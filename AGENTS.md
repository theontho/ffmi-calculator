# Project guidance

- Use direct, evidence-oriented language.
- Avoid safetyism: do not add unnecessary warnings, moralizing, or alarmist copy. Keep material assumptions and limitations concise and specific.
- Whenever calculation models, ranges, input limits, methodology, or external sources change, update both the in-app "Background and sources" section and README.md in the same change. Prefer primary citations and identify extrapolated visual labels as estimates.
